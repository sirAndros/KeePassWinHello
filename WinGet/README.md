# WinGet distribution

This folder contains the release-time pieces needed to publish KeePassWinHello
through the Windows Package Manager Community Repository.

WinGet cannot install the raw `.plgx` plugin artifact directly. The release flow
therefore builds a small Inno Setup installer that finds the local KeePass 2
installation and copies `KeePassWinHelloPlugin.plgx` into its `Plugins` folder.
The manifest generated by `Build-WinGetPackage.ps1` depends on the existing
`DominikReichl.KeePass` winget package.

## Release flow

1. Install Inno Setup 6 on the release machine.
2. Build the plugin and installer:

   ```powershell
   .\Build-WinGetPackage.ps1 `
       -Version 3.3.1 `
       -InstallerUrl https://github.com/sirAndros/KeePassWinHello/releases/download/v3.3.1/KeePassWinHelloPluginSetup-3.3.1.exe
   ```

3. Upload both release artifacts:

   - `releases\KeePassWinHelloPlugin.plgx`
   - `releases\KeePassWinHelloPluginSetup-<version>.exe`

4. Copy the generated files from
   `releases\winget\manifests\s\SirAndros\KeePassWinHello\<version>` into a
   fork of `microsoft/winget-pkgs` under the same path.
5. Validate and submit the manifest PR from the `winget-pkgs` checkout:

   ```powershell
   winget validate .\manifests\s\SirAndros\KeePassWinHello\3.3.1
   ```

The installer URL must be the final immutable GitHub release URL before the
manifest is submitted. If the installer is rebuilt after upload, regenerate the
manifest so `InstallerSha256` matches the uploaded file.
